# Pills Tracker

Локальный трекер лекарств и напоминаний для Android.

Текущая версия: **1.6.0**. Поддерживается Android 8.0 и новее
(`minSdk 26`, `targetSdk 36`).

Изменения текущей версии находятся в [`CHANGELOG.md`](CHANGELOG.md), описание архитектуры —
в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Возможности

- пошаговое создание и редактирование лекарства в единой дизайн-системе;
- горизонтальная бесконечная карусель выбора формы лекарства;
- медицинская палитра из 12 оттенков с ручным включением второго цвета;
- локальный профиль с именем и необязательным возрастом;
- переключаемый упрощённый интерфейс с крупным текстом, большими кнопками и явными действиями;
- персональный главный экран со сводкой, хронологией приёмов и иллюстрацией по времени суток;
- объёмные иконки разных форм лекарств;
- выбор формы таблетки, одного или двух цветов и отдельного фона;
- дозировка с отдельным числовым значением и единицей измерения;
- ежедневные, чередующиеся и недельные расписания;
- несколько времён приёма с отдельными днями недели;
- ручной ввод даты и времени с переключением на календарь или циферблат;
- системные и внутренние напоминания, групповые действия и откладывание на 30 минут;
- понятное включение точных напоминаний в онбординге и настройках с экономным использованием батареи;
- повторные напоминания через 30 минут, затем через 2 часа и каждые 4 часа до конца дня;
- автоматическая отметка пропуска после окончания дня;
- учёт остатка, суммирование купленной упаковки при пополнении и предупреждение при запасе на три дозы;
- лекарства «по необходимости»;
- пауза, архив, возобновление курса и безвозвратное удаление с подтверждением;
- компактный календарь, приёмы и статистика за четыре недели внутри истории;
- динамика соблюдения курса и сравнение с предыдущими 28 днями;
- изменение статуса кнопками или свайпом в обычном режиме и крупными подписанными кнопками в упрощённом;
- полноэкранные сведения о лекарстве с возвратом на непосредственный предыдущий экран;
- быстрые действия с лекарством по удержанию его карточки;
- просмотр фактического времени и явное исправление статуса внутри истории;
- безопасное редактирование расписания без создания приёмов задним числом и повторного списания остатка;
- защита от отметок в будущем; остаток используется только для предупреждений о покупке;
- единая объёмная дизайн-система и наглядный выбор системной, светлой и тёмной тем;
- региональное название «Трекер лекарств» для русского языка;
- полностью локальное хранение данных.

## Требования

- Android Studio с поддержкой Android Gradle Plugin 9.1.1;
- JDK 21 для Gradle (исходный код компилируется с совместимостью Java 17);
- Android SDK 36.

## Сборка и запуск

1. Откройте проект в Android Studio и дождитесь синхронизации Gradle.
2. Запустите конфигурацию `app` на устройстве или эмуляторе.
3. Разрешите приложению отправлять уведомления. Точные напоминания можно дополнительно
   включить во время онбординга или позже в настройках.

Для полной проверки проекта в Windows:

```powershell
.\gradlew.bat clean build --no-daemon --no-parallel
```

После сборки создаются:

- устанавливаемый debug APK:
  `app/build/outputs/pills-tracker/PillsTracker-1.6.0-test.apk`;
- release APK:
  `app/build/outputs/pills-tracker/PillsTracker-1.6.0-release.apk`.
