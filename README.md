# Pills Tracker

Локальный трекер лекарств для Android 16.

Текущая версия: **0.0.2**. Список изменений находится в [`CHANGELOG.md`](CHANGELOG.md).

## Возможности

- пошаговое добавление лекарства;
- выбор формы, одного или двух цветов лекарства;
- отдельное числовое значение и единица дозировки;
- ежедневные, чередующиеся и недельные расписания;
- несколько времён приёма с отдельными днями недели;
- групповые уведомления для лекарств на одно время;
- действия «Принял всё», «Не принял» и «Отложить на 30 минут»;
- автоматическая отметка пропуска через три часа;
- учёт таблеток и предупреждение при остатке трёх доз;
- лекарства «по необходимости»;
- пауза, архив и возобновление курса;
- история по дням с возможностью исправить статус;
- изменение статуса приёма свайпом;
- системная, светлая и тёмная темы;
- полностью локальное хранение данных.

## Запуск

1. Откройте проект в Android Studio.
2. Установите Android SDK 36, если IDE предложит это сделать.
3. Запустите конфигурацию `app` на устройстве или эмуляторе.
4. Разрешите уведомления и точные напоминания.

Debug APK автоматически создаётся с названием и версией:
`app/build/outputs/pills-tracker/PillsTracker-1.0.1-test.apk`.
