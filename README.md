# Pills Tracker

Локальный трекер лекарств и напоминаний для Android.

Текущая версия: **1.0.0**. Поддерживается Android 8.0 и новее
(`minSdk 26`, `targetSdk 36`).

История релизов находится в [`CHANGELOG.md`](CHANGELOG.md), описание архитектуры —
в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Возможности

- пошаговое создание и редактирование лекарства;
- объёмные иконки разных форм лекарств;
- выбор формы таблетки, одного или двух цветов и отдельного фона;
- дозировка с отдельным числовым значением и единицей измерения;
- ежедневные, чередующиеся и недельные расписания;
- несколько времён приёма с отдельными днями недели;
- уведомления, групповые действия и откладывание на 30 минут;
- автоматическая отметка пропуска через три часа;
- учёт остатка и предупреждение при запасе на три дозы;
- лекарства «по необходимости»;
- пауза, архив и возобновление курса;
- месячный календарь истории с плановым и фактическим временем;
- изменение и исправление статуса кнопками или свайпом;
- защита от отметок в будущем и при недостаточном остатке;
- системная, светлая и тёмная темы;
- полностью локальное хранение данных.

## Требования

- Android Studio с поддержкой Android Gradle Plugin 9.1.1;
- JDK 17;
- Android SDK 36.

## Сборка и запуск

1. Откройте проект в Android Studio и дождитесь синхронизации Gradle.
2. Запустите конфигурацию `app` на устройстве или эмуляторе.
3. Разрешите приложению отправлять уведомления и точные напоминания.

Для полной проверки проекта в Windows:

```powershell
.\gradlew.bat clean build --no-daemon --no-parallel
```

После сборки создаются:

- устанавливаемый debug APK:
  `app/build/outputs/pills-tracker/PillsTracker-1.0.0-test.apk`;
- неподписанный release APK:
  `app/build/outputs/pills-tracker/PillsTracker-1.0.0-release.apk`.

Для публикации release APK необходимо настроить собственный keystore и release-подпись.

## Данные и разрешения

Данные хранятся локально на устройстве. Доступ к интернету приложению не требуется.
Разрешения на уведомления, точные будильники и запуск после перезагрузки используются
только для своевременных напоминаний о приёме.
